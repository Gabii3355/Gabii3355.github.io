## Projects

### Master's Thesis

A computational chemistry project focused on the sequence-dependent spontaneous deamination of cytosine and 5-methylcytosine in DNA. The project includes MED and DTSS analyses, visualizations of interaction energies and Python scripts for data processing.

### Machine Learning Interatomic Potential for Formic Acid Dimer

A molecular modeling and machine learning project based on the preparation and validation of a machine learning interatomic potential.

### FASTQ Quality Control in R
Bioinformatics project focused on sequencing read quality analysis, filtering and trimming of FASTQ data.
